# Reserve Meet

Браузерное расширение для Vivaldi / Chromium: со страницы урока собирает учеников и открывает персональную Jitsi-комнату на каждого.

История версий: [CHANGELOG.md](CHANGELOG.md).

## Установка в Vivaldi

1. Соберите проект:

```bash
npm install
npm run build
```

2. Откройте `vivaldi://extensions`.
3. Включите **Режим разработчика**.
4. **Загрузить распакованное** → папка `dist`.

На странице урока нажмите иконку Reserve Meet или `Alt+Shift+R`. Откроется боковая панель со списком учеников. `Alt+Shift+U` обновляет список. Если сочетания заняты, назначьте их в настройках горячих клавиш браузера.

## Что делает

- Читает имена из `data-first_name` / `data-user_id` на странице урока, не из видимого текста.
- Группирует учеников по слоту: 2 часа, 1-й час, 2-й час.
- Создаёт уникальные Jitsi-ссылки и помнит их для урока даже после перезапуска браузера.
- По умолчанию открывает вкладки в **новом окне**, в порядке списка. В настройках можно выбрать текущее окно.
- Копирует сообщение ученику и Slack: имя как гиперссылка на профиль, список можно взять целиком по часам.

Шаблоны и адрес Jitsi — в настройках расширения.

## Проверка без платформы школы

Откройте `fixtures/lesson.html` в Vivaldi (через локальный сервер или как файл). Если это `file://`, в карточке расширения включите **Доступ к файловым URL**. Затем нажмите иконку Reserve Meet: должны появиться Матвей, Тимофей, два Ивана и Халим Магомедов.
