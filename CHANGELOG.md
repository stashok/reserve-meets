# История изменений

## 0.3.2 — 2026-08-17

- В Slack больше нет заголовков «2 часа» / «1-й час» / «2-й час».
- Если ссылки ещё нет, в строке статус «нет ссылки».
- Группы часов можно сворачивать.
- Вкладки по-прежнему в одном окне: сначала двухчасовые, затем 1-й час, затем 2-й. Двухчасового не дублируем во втором окне.

## 0.3.1 — 2026-08-17

- У ученика со ссылкой в строке статуса тихие действия «Ученику» и «Slack» — можно скопировать одного в чат, не трогая группу.

## 0.3.0 — 2026-08-17

- Светлый спокойный интерфейс: один список учеников, короткая кнопка «Создать комнаты», Slack у группы часов. Меню иконки — панель и один переключатель поп-апа. Шаблоны в настройках свёрнуты.

## 0.2.9 — 2026-08-17

- В имя Jitsi-комнаты добавляется уникальный код этой установки расширения, чтобы ссылки разных тренеров не пересекались. Уже запомненные ссылки не меняются.

## 0.2.8 — 2026-08-17

- Логика боковой панели откачена к поведению браузера по умолчанию: «Открыть панель» открывает её в текущем окне, без прыжка на урок и без закрытия на других вкладках.

## 0.2.7 — 2026-08-17

- «Открыть панель» с другой вкладки сразу вызывает open() по клику, затем переключает на урок — панель больше не требует второго клика.
- Новое окно Jitsi грузит заглушку, которая сама закрывает панель, если это не окно урока. Так убирается пустая белая полоса, которую API не закрывал.
- В Vivaldi панель общая на окно урока: на соседних вкладках этого окна она тоже видна. В Chrome она может быть только на вкладке урока.

## 0.2.6 — 2026-08-17

- Панель открывается только в окне урока: с другой вкладки переключение идёт туда, на остальных окнах панель закрывается.
- Перед первым окном Jitsi панель урока временно закрывается, чтобы новое окно не копировало белую полосу.

## 0.2.5 — 2026-08-17

- Боковая панель выключена везде по умолчанию и включается только на вкладке урока. Новые окна Jitsi открываются без белой панели.

## 0.2.4 — 2026-08-17

- Вкладки Jitsi больше не открываются с пустой белой боковой панелью.
- Кнопки «Открыть» и «К звонку» снова работают после закрытия и повторного открытия панели и показывают, открыта ли вкладка.

## 0.2.3 — 2026-08-17

- Горячие клавиши убраны. Клик по иконке открывает меню: панель урока, показать или скрыть поп-ап на вкладке Jitsi.

## 0.2.2 — 2026-08-17

- Горячие клавиши снова видны в списке сочетаний Vivaldi. Предупреждение, если сочетание занято поиском браузера (например Ctrl+Shift+G).

## 0.2.1 — 2026-08-17

- Горячие клавиши настраиваются в опциях расширения: нажать кнопку и задать сочетание.
- Боковая панель остаётся на вкладке урока. На вкладках Jitsi её нет — там только маленький оверлей.

## 0.2.0 — 2026-08-17

- Вкладки открываются в порядке списка учеников; группировка Chromium убрана — в Vivaldi она не работала.
- По умолчанию комнаты открываются в новом окне; в настройках можно выбрать текущее окно.
- У каждого ученика есть кнопка «Открыть» / «К звонку» без пересоздания остальных комнат.
- В списке видно, у кого уже есть ссылка и у кого вкладка открыта.
- Ссылки на комнаты хранятся локально и переживают перезапуск браузера.
- Slack копируется пачками по часам; у каждой группы есть своя кнопка Slack.
- Горячие клавиши: Alt+Shift+R — панель, Alt+Shift+U — обновить список.
- Перед закрытием вкладки, в которой сейчас идёт звонок, спрашивается подтверждение.

## 0.1.6 — 2026-08-17

- Ссылка Jitsi запоминается на ученика в рамках урока и не меняется при повторном создании.
- Повторное создание не закрывает вкладки тех, кто остался выбран.
- Галочки выбора у групп «2 часа», «1-й час», «2-й час»; номера групп убраны.
- Slack копирует имя и фамилию как гиперссылку на профиль.

## 0.1.5 — 2026-08-16

- Оверлей на вкладке Jitsi: копирование для ученика и Slack, сворачивание в чип с именем.
- Имя в списке — имя и фамилия из `data-*`, без статусов со страницы.
- Ссылка на профиль берётся из `a.title-name`.

## 0.1.0

- Первый рабочий вариант: извлечение учеников со страницы урока, комнаты Jitsi, боковая панель и настройки.
